# Experience Log

A chronological record of lessons learned, mistakes, discoveries, and practical improvements.

The purpose of this repository is to turn daily experiences into reusable knowledge. Each entry is organized by date and contains an English version followed by a Chinese version so that the lessons remain easy to review and reuse.

## Repository structure

```text
.
├── README.md
├── TEMPLATE.md
└── logs/
    └── YYYY-MM-DD.md
```

## How to add an entry

1. Copy `TEMPLATE.md` into the `logs/` directory.
2. Rename it using the date format `YYYY-MM-DD.md`.
3. Write the English version first and the Chinese version second.
4. Keep only the `Lessons Learned` section in each log.
5. Review the entry before committing it.

## Principles

- Understand the documentation before taking action.
- Spend enough time understanding the problem early; rushed preparation often creates more work later.
- Review pull requests carefully. A thorough review can prevent rework and improve overall efficiency.
- Keep the project root clean. Put logs, notes, scripts, and supporting materials in clearly named directories.
- Record specific actions and decisions instead of vague conclusions.
- Number and title every table and figure. Keep numbering sequential and use the same references in the text and captions.
- Use one formatting standard for English, Chinese, code, tables, headings, captions, spacing, punctuation, and alignment.
- Describe every test with its conditions, content, result, and result analysis. Never present an isolated measurement without context.

## Entry format

Each entry must follow this order:

1. English `Lessons Learned`.
2. Chinese `经验总结`.

Each entry should contain only these two sections unless the repository documentation is deliberately changed.
