# Attention 总结（2026-10-02）

Attention 的过程可以这样写：

当前 token 在这一层的 hidden state 是：

\[
h_i
\]

先经过 RMSNorm，稳定向量的数值尺度：

\[
\tilde h_i=\operatorname{RMSNorm}(h_i)
\]

再通过三个不同的线性投影，生成 Query、Key、Value：

\[
q_i'=\tilde h_iW_Q,\qquad
k_i'=\tilde h_iW_K,\qquad
v_i=\tilde h_iW_V
\]

其中：

- \(q_i'\)：当前 token 用来“查询”的特征；
- \(k_i'\)：当前 token 提供给别人匹配的特征；
- \(v_i\)：当前 token 真正携带的信息。

接着对 Query 和 Key 加入位置信息：

\[
q_i=\operatorname{RoPE}(q_i',i),\qquad
k_i=\operatorname{RoPE}(k_i',i)
\]

这样，Query 和 Key 不仅包含 token 内容，也包含 token 在序列中的位置。

当前 token 的 Query 会和每个历史 token 的 Key 计算匹配分数：

\[
s_{ij}=\frac{q_i k_j^T}{\sqrt d}
\]

分数越大，表示当前 token 越关注历史 token \(j\)。

然后对所有分数做 softmax：

\[
\alpha_{ij}=\operatorname{softmax}(s_{ij})
\]

得到 attention weight，最后用这些权重加权历史 Value：

\[
\operatorname{output}_i=\sum_j \alpha_{ij}v_j
\]

所以完整过程是：

\[
h
\rightarrow
\operatorname{RMSNorm}
\rightarrow
Q,K,V
\rightarrow
\operatorname{RoPE}(Q,K)
\rightarrow
QK^T
\rightarrow
\operatorname{softmax}
\rightarrow
\sum \alpha V
\]

其中，KV cache 保存的是历史 token 的 \(K\) 和 \(V\)，让新的 Query 可以直接和它们匹配。
